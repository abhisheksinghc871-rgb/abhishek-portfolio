# Abhishek Singh Chauhan — DevOps Portfolio

This repository contains the static HTML portfolio of Abhishek Singh Chauhan.

## Run locally

Open `index.html` in a modern browser.

## Deploy to GitHub + Vercel

This is a static HTML site. No Node.js, React, Vite, build command, or server is required.

- Put `index.html` in the repository root.
- If using a profile photo, place it beside `index.html` as `profile.jpg`.
- Import the GitHub repository into Vercel.
- Framework Preset: **Other** (or leave Vercel's static-site detection as appropriate).
- Build Command: leave empty.
- Output Directory: leave empty / root.

The original portfolio's HTML, embedded CSS, embedded JavaScript, animations, content, and links are intentionally kept intact.
